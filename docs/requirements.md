# Todo App 要件定義書

- 版: 1.0 (2026-11-04)
- リポジトリ: https://github.com/iwasaki-hub/todo-app
- 本番URL: https://todo-app-phi-one-43.vercel.app/

## 目的
ログイン不要で、ブラウザから個人用タスクをすばやく管理できるシンプルなTodoアプリを作成する。学習目的としてReact + Vite + TypeScript、テスト、GitHubとVercelのデプロイ運用を実践する。

## スコープ (MVP)
1. タスクをテキストで追加できる。
2. タスク本文を編集できる。
3. タスクを削除できる（誤削除防止の確認方法は実装時に一貫させる）。
4. 完了/未完了を切り替えられる。
5. 「すべて」「未完了」「完了」のフィルターを切り替えられる。
6. 同一ブラウザの localStorage に保存し、再読込後も維持する。
7. タスク0件の空状態と、入力エラーをわかりやすく表示する。
8. PC・スマートフォンの幅で利用でき、キーボードで基本操作できる。

## スコープ外 (MVP)
ログイン・アカウント管理、クラウド同期、通知、期限、ドラッグ&ドロップ、外部API、データベース、リアルタイム共有、モノレポ。

## 機能・受入基準
| ID | 機能 | 受入基準 |
|---|---|---|
| F-01 | 追加 | 前後の空白を除去して保存。空文字/空白のみは登録不可。Enterまたはボタンで追加できる。 |
| F-02 | 編集 | 既存テキストを変更できる。空白のみへの変更は不可。キャンセルで元のまま。 |
| F-03 | 削除 | 対象の1件のみ削除され、保存内容にも反映される。 |
| F-04 | 完了切り替え | チェック操作で完了状態が反転し、再読み込み後も維持される。 |
| F-05 | フィルター | 全件・未完了・完了を正しく表示。切替ではデータを消さない。 |
| F-06 | 永続化 | 正常な保存データを再読込時に復元する。破損データはアプリが白画面にならず、安全に初期化できる。 |
| F-07 | 空状態 | フィルター結果が0件なら適切なメッセージを表示。 |
| F-08 | アクセシビリティ | ラベル、フォーカス表示、ボタンの役割、キーボード操作を確保。 |

## 非機能要件
- バックエンドを不要とする。`localStorage` は端末・ブラウザごとに独立しており、同期やバックアップは保証しない。
- 保存データには機微情報を入力しない前提とし、ログや外部送信を行わない。
- TypeScriptの型検査、ESLint、ビルドが成功する。
- GitHubの`main`をVercel Productionに公開する。Preview環境での検証を優先する。
- 公開URLを維持する。デプロイ設定の変更は必要になった際に限る。

## データ仕様
Todo: `id: string`, `title: string`, `completed: boolean`, `createdAt: string`, `updatedAt: string`。
日時はISO 8601文字列。idは原則 `crypto.randomUUID()` で生成する。
