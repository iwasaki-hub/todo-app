## 実装と設計判断

- タスクごとの編集フォーム、保存・キャンセル、入力エラー表示を追加した。前後の空白を除去し、空白のみ・200文字超を拒否する。
- `useTodos.updateTodo` は対象IDだけを不変更新し、本文が変わった場合だけ `updatedAt` を更新する。ID・完了状態・作成日時は保持する。未知IDはエラーを返し、無関係なデータを変更しない。同じ本文の保存は書き込みを行わない。
- 最新のTodo配列をrefにも保持し、再描画前の連続操作で古い配列を使わないようにした。保存はイベントから呼ぶ共通処理内で行い、Reactのstate updater内では副作用を実行しない。
- 保存キー `todo-app:todos:v1` と保存データ型を維持した。初期化は読み取りのみで、破損データを初期表示時に上書きしない。保存失敗時は従来どおりメモリー上の操作を維持し、画面上部に保存エラーを表示する。
- Appがフィルター状態と表示対象の導出を担当する。TodoFilters → App → TodoList → TodoItemの順に表示を渡し、更新コールバックはuseTodosへ戻す。フィルター状態は永続化しない。
- すべて・未完了・完了の切り替え、選択状態の `aria-pressed`、フィルター別の空状態を追加した。全件数と完了件数は元の配列から計算する。
- 編集開始時は入力欄を選択し、保存・キャンセル後は編集ボタンへフォーカスを戻す。Escによるキャンセル、日本語入力中のEnter誤送信抑止を実装した。
- 既存のCSSにボタン・フィルター・編集フォーム・狭い画面での折り返しを追加した。大規模な再デザインは行っていない。
